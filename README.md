# Tower Defense Game (Godot)

A fast-paced tower defense game built with the Godot Engine. Defend your base against waves of enemies by strategically placing and upgrading towers, managing resources, and adapting to increasingly difficult challenges.

---

## 🎮 Features

* 🧠 Strategic tower placement and path control
* 🔫 Multiple tower types (e.g. basic, splash, slow, sniper)
* 📈 Upgrade system for improving tower power and efficiency
* 👾 Diverse enemy types with unique behaviors
* 🌊 Progressive wave system with increasing difficulty
* 💰 Resource management (earn and spend wisely!)
* 🗺️ Multiple maps with different layouts

---

## 🛠️ Built With

* [Godot Engine](https://godotengine.org/) (version 4.x recommended)
* GDScript

## 🧩 Game Mechanics

### Towers

* Each tower has unique stats (damage, range, fire rate)
* Some towers apply effects (slow, poison, splash damage)

### Enemies

* Different enemy types: fast, tanky, flying, boss
* Enemies follow predefined paths

### Economy

* Earn gold by defeating enemies
* Spend gold on towers and upgrades
